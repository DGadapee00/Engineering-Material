# Engineering Material

A typeset mechanical engineering cheat sheet rebuilt from a handwritten notebook by Andy Sadhwani. It covers structural mechanics, fatigue and fracture, fluids, gas dynamics, rocket mechanics, orbits, vibration and an analysis checklist.

**Live page:** https://dgadapee00.github.io/Engineering-Material/

## Files

- `engineering-notebook.html` is the cheat sheet. The equations are typeset with MathJax, which loads from a CDN, so the page needs an internet connection.
- `index.html` redirects the site root to the cheat sheet.

## Notes

Values were transcribed from a photo of the notebook and checked against enlarged crops. Check any value against a reference before using it in a real calculation. The schematics are simplified redraws, not copies of the original sketches.
